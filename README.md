# Yogesh Awate — Portfolio

A premium, responsive portfolio built with React and Vite.

## Run in VS Code

1. Open this `yogesh-portfolio` folder in VS Code.
2. Open the integrated terminal.
3. Run `npm install`.
4. Run `npm run dev`.
5. Open the local URL shown in the terminal (usually `http://localhost:5173`).

## Production build

Run `npm run build`. The optimized site will be created in `dist/`.

## GitHub Pages

The included GitHub Actions workflow builds and deploys every push to `main`.
In the repository settings, set **Pages → Build and deployment → Source** to
**GitHub Actions**. Relative Vite asset paths support both root user sites and
project sites.
